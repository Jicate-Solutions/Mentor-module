## 💡 Glassmorphism Design System

### Glass Hierarchy

**Level 1 - Background:**
- `.bg-frosted` - Frosted background with pattern
- `.bg-mesh-gradient` - Multi-gradient mesh
- Purpose: Create base layer with depth

**Level 2 - Containers:**
- `.glass-sidebar` - Main navigation (20px blur)
- `.glass-header` - Top header bar (16px blur)
- `.glass-card` - Standard content cards (14px blur)
- Purpose: Create primary content containers

**Level 3 - Interactive Elements:**
- `.glass-nav-item` - Navigation items (8px blur)
- `.glass-nav-item-active` - Active state with green tint
- `.glass-button` - Interactive buttons
- Purpose: Clickable, hoverable elements

**Level 4 - Overlays:**
- `.glass-modal` - Modal dialogs (20px blur, 90% opacity)
- `.glass-overlay` - Backdrop overlays (6px blur)
- `.glass-dropdown` - Dropdowns and selects
- Purpose: Floating UI elements

## 🔧 Technical Details

### CSS Properties Used

**Backdrop Filter:**
```css
backdrop-filter: blur(12px) saturate(180%);
-webkit-backdrop-filter: blur(12px) saturate(180%);
```

**Semi-Transparent Backgrounds:**
```css
background: rgba(255, 255, 255, 0.75);
```

**Soft Borders:**
```css
border: 1px solid rgba(255, 255, 255, 0.45);
```

**Subtle Shadows:**
```css
box-shadow:
  0 8px 32px rgba(11, 109, 65, 0.08),
```
